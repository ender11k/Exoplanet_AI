The Challenge

The Kepler Space Telescope generated millions of light curves. Manually identifying the microscopic dip in a star's brightness caused by an orbiting exoplanet is computationally expensive and prone to human error due to cosmic noise and stellar flares.

This research introduces a novel hybrid pipeline. By utilizing a 1D Convolutional Neural Network (CNN) to automatically extract complex spatial features from raw flux data, and feeding those engineered features into an Extreme Gradient Boosting (XGBoost) classifier, we significantly reduce false positives and improve detection accuracy.

Dataset & Pre-processing

  • Data Source: NASA Kepler Space Telescope
  • Data Type: Time-Series Photometry
  • Noise Reduction: Savitzky-Golay Filtering
  • Normalization: Zero-Mean / Min-Max Scaling
  • Target Output: Binary (Exoplanet / False Positive)
